Technical and Design Achievements Description
---
The technical and design achievements go hand-in-hand, as all the functions created also have some sort of CSS elements included within them. For instance, linked views are shown in two information boxes that change upon clicking a shape. The information box in the top right corner gives a general description of each type of shape while the information box in the bottom right provides the user with a link to the Wikipedia article for the specific shape. Both of these information boxes, as well as the tooltips, were made utilizing HTML and CSS elements such as positioning, padding, shape, color, and font. 

Beyond the technical and design achievements for the functions that create the tooltips and linked views via the information boxes, general design efforts such as differentiating the color between the SVG container and the overall background was included. Furthermore, differences in font styles, sizes, and colors were chosen based on personal aesthetic choices. The overall "list" of technical and design achievements that go beyond basic requirements would be: two additional shapes (Arc and Wye), linked views, hovering, fixed labels, popups/tooltips, interactivity with responsiveness through internal response and external links, and overall colorfulness.
